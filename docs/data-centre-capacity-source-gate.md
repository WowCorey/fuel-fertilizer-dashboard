# Australian Data Centre Capacity Source Gate

## Current status

Fuel Resilience AU does not currently publish a national numerical series for Australian data-centre capacity, electricity demand, AI-cluster capacity or available compute.

No canonical Australian government register was identified in the reviewed source set that provides a current, nationally consistent and reusable measure of:

- operational data-centre capacity in megawatts;
- committed and proposed capacity using one public definition;
- facility-level electricity demand;
- accelerator or AI-compute capacity;
- available versus contracted capacity.

The corresponding source envelope therefore remains **unavailable**.

## What is deliberately excluded

The dashboard does not substitute:

- vendor marketing claims;
- consultancy market estimates;
- paywalled industry databases;
- media-compiled project lists;
- planning applications treated as operating capacity;
- announced capacity treated as commissioned capacity.

Those materials may be useful research leads, but they are not interchangeable with a canonical national public register.

## Inclusion test

A future source can pass this gate only when it provides:

1. a named accountable publisher;
2. a stable public landing page or machine-readable endpoint;
3. clear definitions for operating, committed, proposed and retired capacity;
4. a stated unit and reference date;
5. coverage boundaries and known omissions;
6. a lawful reuse basis;
7. a reproducible extraction and validation method.

## Claim boundary

An unavailable dashboard value does not mean Australia has no data centres or no capacity. It means this project has not loaded a source that satisfies the public-source and reproducibility requirements above.
